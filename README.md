# Django Native Authentication with JWT with Email Handling

This is a learning project aimed to implement Fully Endpoints regard authentication, signup login & logout APIs.

## Technologies
- Python
- DjangoRestFramework
- Celery
- djangorestframework-simplejwt
- django-cors-headers

## Features
- Signup API
- Login API
- Change Password Api
- Reset Password by Email API
- background Email Handling
- Signup welcome email
- Reset password validation by sending click link to email
- Handling HTML & Plain text Email contents
